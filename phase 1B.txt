11. iOS 26 Liquid Glass Design System & Animation Guidelines
Native iOS 26 SwiftUI Liquid Glass Implementation
Unlike older iOS 15–18 .ultraThinMaterial blurs that only perform a static Gaussian blur, iOS 26 introduces public hardware-accelerated Liquid Glass APIs in SwiftUI (GlassEffectContainer, .glassEffect(_:in:isEnabled:), .glassEffectID(_:in:), .glassEffectUnion(id:namespace:), and .glassEffectTransition(_:)).

Core Architectural Rules (Apple HIG iOS 26 Compliance)
Strict Layer Separation: Liquid Glass is used exclusively on the floating functional and navigation layer (Mini-Player capsule, transport controls, filter pills, top search bar) hovering over the content and atmosphere layer (MeshGradient + album art + lyrics). Never stack a .glassEffect() view directly inside another .glassEffect() view.

Grouped Rendering via GlassEffectContainer: Wrap adjacent glass controls inside GlassEffectContainer(spacing: 16) { ... }. SwiftUI renders all child glass shapes in a single shared Metal pass, improving GPU performance and allowing neighboring capsules to organically blend and morph into one another as they move closer than spacing.

Morphing Transitions via .glassEffectID: Pair @Namespace private var glassNamespace with .glassEffectID("miniToFullPlayer", in: glassNamespace) and .glassEffectTransition(.matchedGeometry) so the compact Mini-Player capsule physically stretches and refracts into the full Now Playing control bar.

// Canonical iOS 26 Liquid Glass Transport Bar Pattern

}

Core Swift 6 Domain Protocol Contracts
Swift
import Foundation
import SwiftUI

public enum PlaybackConnectionState: Sendable, Equatable {
    case disconnected
    case connecting
    case connectedLocalIPC          // SPTAppRemote active (<15ms latency)
    case connectedCloudWebAPI       // Fallback HTTP Connect control
    case rateLimited(retryAfter: TimeInterval)
    case error(String)
}

public struct PlaybackSnapshot: Sendable, Equatable {
    public let trackURI: String
    public let title: String
    public let artist: String
    public let album: String
    public let artworkURL: URL?
    public let durationMs: Int
    public let anchorPositionMs: Int
    public let anchorMonotonicTime: TimeInterval // CACurrentMediaTime()
    public let isPlaying: Bool
    public let shuffleEnabled: Bool
    public let repeatMode: RepeatMode
    public let activeDeviceName: String
}

@MainActor
public protocol PlaybackControllerProtocol: AnyObject {
    var connectionState: PlaybackConnectionState { get }
    var currentSnapshot: PlaybackSnapshot? { get }
    var onSnapshotUpdate: ((PlaybackSnapshot) -> Void)? { get set }

    func connect() async throws
    func disconnect()
    func play(uri: String?) async throws
    func pause() async throws
    func skipNext() async throws
    func skipPrevious() async throws
    func seek(toPositionMs: Int) async throws
    func setShuffle(_ enabled: Bool) async throws
    func setRepeatMode(_ mode: RepeatMode) async throws
}

public enum LyricsSyncGranularity: String, Codable, Sendable {
    case syllableSynced   // Enhanced LRC <mm:ss.xx> or TTML word spans
    case lineSynced       // Standard LRC [mm:ss.xx]
    case plainText        // Unsynchronized text
    case instrumental     // Explicit instrumental track
    case unavailable      // Not found
}

public struct LyricWordToken: Codable, Sendable, Equatable, Identifiable {
    public let id: UUID
    public let text: String
    public let startTimeMs: Int
    public let endTimeMs: Int
}

public struct LyricLine: Codable, Sendable, Equatable, Identifiable {
    public let id: UUID
    public let startTimeMs: Int
    public let endTimeMs: Int
    public let text: String
    public let words: [LyricWordToken] // Non-empty when syllableSynced
}

public struct LyricsPayload: Codable, Sendable, Equatable {
    public let trackURI: String
    public let sourceProvider: String
    public let granularity: LyricsSyncGranularity
    public let lines: [LyricLine]
    public let plainTextFallback: String?
    public let userOffsetMs: Int
    public let fetchedAt: Date
}

public protocol LyricsProviderProtocol: Sendable {
    var providerName: String { get }
    func fetchLyrics(
        trackURI: String,
        title: String,
        artist: String,
        album: String,
        durationMs: Int
    ) async throws -> LyricsPayload?
}

20. Privacy, PKCE & Zero-Secret Repository Security Plan
Public GitHub Repo Safety (Zero Secrets in Source Code):

To get unlimited free macos-latest Xcode 26 build minutes on GitHub Actions, your repository is public.

Hard Rule: No client_secret, no hardcoded client_id, no .p12 certificates, and no .mobileprovision profiles ever exist in git. Signing happens 100% locally on your iPhone 14 Pro inside SideStore after downloading the unsigned .ipa.

RFC 7636 OAuth 2.0 PKCE Implementation (SpotifyPKCEAuthenticator.swift):

Generates a 64-byte cryptographically random code_verifier using SecRandomCopyBytes.

Computes code_challenge = base64URLEncode(SHA256(ASCII(code_verifier))) using Apple's CryptoKit.

Requests authorization via ASWebAuthenticationSession with linerios://auth-callback and validates the state parameter to prevent CSRF injection.

Hardware Keychain Isolation (KeychainStore.swift):

Stores access_token, refresh_token, token_expiry, and client_id using kSecClassGenericPassword with protection class kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly—meaning tokens are hardware-encrypted by the A16 Secure Enclave and are never included in unencrypted iTunes/Finder backups.

Zero Third-Party Telemetry: The app makes outbound HTTPS connections to only two domains: *.spotify.com (accounts.spotify.com, api.spotify.com, i.scdn.co) and lrclib.net.
